# ¿Quieres solucionar tu tema con la damisela? 💖

> *"No sé, tú eres el ingeniero..."* — Respuesta de ingeniería aplicada a problemas del corazón.

Aplicación web interactiva para resolver el dilema del chat de WhatsApp:
- Pregunta oficial: **¿Quieres solucionar tu tema con la damisela? Si o No marque con una X**
- Botón **SÍ** interactivo con dibujo de la **X** oficial, confeti de corazones y enlace directo a WhatsApp.
- Botón **NO** esquivo ("Muchas veces perdemos las cosas más bonitas por orgullo...").
- Mobile-first, responsive y diseñado especialmente para compartir por chat.
